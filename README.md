# もにBot セットアップ手順

「今日の目標」チャンネルの達成/未達成を自動判定して、
「もに監視所」「悲鳴」チャンネルに自動で通知するBotです。

## このBotがやること

1. 毎日深夜1時(日本時間)に「今日の目標」チャンネルの最新投稿をチェック
2. 番号(1️⃣2️⃣3️⃣…)ごとに ✅ がついてるか数える
3. 全部達成 → 「もに監視所」に連続達成日数つきでお祝い投稿
4. 未達成あり → 「もに監視所」に未達成項目を通知し、1時間反応(リアクション)が無ければ「悲鳴」チャンネルで自動的に騒ぐ
5. 本文に🌙が含まれる日は「お休み日」としてスキップ
6. 活動時間帯(設定で変更可)に「悲鳴」チャンネルへの投稿が1時間以上無いと、「もに監視所」に「動いてる?」と自動投稿(1日1回まで)

---

## ステップ1: 必要な情報をそろえる

Discordの設定 → 詳細設定 → 「開発者モード」をON にしてから:

- **配信者本人のユーザーID**: 自分のアイコンを右クリック →「IDをコピー」
- **今日の目標チャンネルのID**: チャンネルを右クリック →「IDをコピー」
- **もに監視所チャンネルのID**: 同上
- **悲鳴チャンネルのID**: 同上
- **Botのトークン**: Discord Developer Portalで取得したもの

これらを `.env.example` を参考にメモしておいてください。

---

## ステップ2: GitHubにコードを置く(Railwayで動かすために必要)

1. https://github.com でアカウントを作る(無料)
2. 右上の「+」→「New repository」で新しいリポジトリを作成(例: `moni-bot`、Publicで可)
3. このフォルダの中身(`index.js`, `package.json`, `.gitignore`, `.env.example`)を、
   GitHubの画面上の「Add file」→「Upload files」からドラッグ&ドロップでアップロード
   (`.env` 自体は絶対にアップロードしないこと。`.env.example` だけでOK)
4. 「Commit changes」で保存

---

## ステップ3: Railwayでデプロイ

1. https://railway.app にアクセスし、GitHubアカウントでログイン
2. 「New Project」→「Deploy from GitHub repo」→ 先ほど作ったリポジトリを選択
3. デプロイが始まったら、プロジェクト画面の「Variables」タブを開き、
   `.env.example` に書いてある項目を1つずつ、実際の値で設定する
   (DISCORD_TOKEN, STREAMER_USER_ID, CHANNEL_GOAL_ID, CHANNEL_WATCH_ID, CHANNEL_SCREAM_ID, ACTIVE_HOURS_START, ACTIVE_HOURS_END)
4. 設定を保存すると自動的に再起動して、Botが起動する
5. 「Deployments」タブのログに `ログイン成功: (Bot名)` と表示されればOK

---

## 注意点

- `state.json`(連続達成日数の記録)はRailwayのファイルシステムに保存されますが、
  再デプロイのタイミングでリセットされる可能性があります。まずはこの簡易構成で運用してみて、
  問題が出てきたら後でデータベース(Railway内のPostgresなど)に切り替えられます。
- Botのトークンは絶対に人に見せたり、コードに直接書いたりしないでください。
  もし漏れたと思ったら、Developer PortalでReset Tokenしてください。
- 「今日の目標」の文章フォーマット(`1️⃣文章→✅`のように番号絵文字で始まる行)が変わると、
  Botが正しく数えられなくなるので、フォーマットはできるだけ揃えてください。

---

## 動作テストしたい時

深夜1時を待たずに動作確認したい場合は、`index.js` の中の

```js
cron.schedule('0 1 * * *', () => {
```

の部分を、例えば「5分後」のようなテスト用スケジュールに一時的に書き換えて、
Railwayに再デプロイすれば、すぐに動きを確認できます。確認できたら元に戻してください。
